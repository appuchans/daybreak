# Daybreak

A simple phone-friendly top-news page. Single static file, no build step.

Open `index.html` in a browser, or host it on any static host and add it to your phone's home screen.

Stories are an embedded snapshot (3 October 2026) in the `S` array in `index.html`; each card links to its source. Live fetching needs a news API and a small backend or CORS proxy, which is not built yet.
